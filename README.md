Hairnic — Static Website Showcase
=================================

Overview
--------

Hairnic is a lightweight, static website template for showcasing products, services, or personal portfolios. It uses plain HTML, CSS, and JavaScript and includes common pages such as a homepage, product, blog, contact, and testimonial pages.

Free to Showcase
-----------------

This project is free to use and showcase. Feel free to fork the repository, customize the design, and add it to your portfolio or profile.

What's Included
---------------

- `index.html` — Landing page
- `product.html`, `blog.html`, `about.html`, `contact.html`, `feature.html`, `testimonial.html` — Example pages
- `css/` — Styles including `bootstrap.min.css` and `style.css`
- `js/` — Main JavaScript
- `img/` — Images used by the template
- `lib/` — Third-party libraries (Owl Carousel, Wow.js, etc.)

Quick Start
-----------

1. Clone or download the project.
2. Open `index.html` in your browser to preview locally.
   - Or run a simple static server, e.g.:

```bash
python -m http.server 8000
# then open http://localhost:8000
```
